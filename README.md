**E Scope International** is a Sri Lanka-based software company headquartered in **Homagama**. We design and build modern software for businesses, from point-of-sale to AI platforms and smart farming.

| 🚀 What we build | 📌 Details |
| :-- | :-- |
| 💼 **Business Management Software** | POS systems (desktop, web and mobile), inventory, billing and reporting |
| 🤖 **AI-Driven Platforms** | AI engineering: intelligent tools that automate decisions and customer experiences |
| 🌾 **Smart Agriculture Solutions** | Technology that helps farmers monitor, manage and grow better |
| 🌐 **Web & Mobile Development** | Business websites, e-commerce, booking platforms and custom apps |

### 📦 Our Products

| Product | Description | Stack |
| :-- | :-- | :-- |
| **FlowPOS** | Complete POS ecosystem: Desktop, Web and Mobile | C# WinForms · React · Go · React Native · PostgreSQL |
| **Ticket Wave** | Event ticketing with QR tickets and gate scanning | Rust · React · Tailwind · PostgreSQL |
| **Velra** | QR-to-table hospitality and AI dining platform | Multi-tenant · AI |
| **Custom Web Apps** | E-commerce, tourism booking and business sites | Next.js · WordPress · Go |
